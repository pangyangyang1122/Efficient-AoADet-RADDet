# Efficirnt-AoADet-RADDet

## abstract
### Millimeter-wave radar is essential in autonomous systems due to its robustness in adverse visual conditions. In actual application, Range-Azzimuth-Doppler (RAD) tensor-based methods reduce manual parameter dependence compared to point cloud processing but face key challenges: (1) the computational and memory burdens of 3D tensor processing hinder deployment on resource-constrained platforms; (2) inherent radar data anisotropy combined with conventional networks' limited cross-dimensional learning capability compromises detection accuracy. To overcome these challenges, we propose Efficient-AoADet, an efficient radar detection framework that introduces three key innovations: First, a joint optimization architecture that unifies angle of arrival (AoA) estimation and object detection using compact Range-Doppler (RD) spectrums as input, achieving 60\% computation reduction and order-of-magnitude memory savings. Second, a dynamic AoA refinement mechanism that adapts estimation parameters to detection tasks, which improves the angular resolution of the object and has clutter suppression capability.  Third, we introduce a lightweight Inter-Dimensional Attention (InterDim-Attn) module into the object detection network, which explicitly enforces cross-dimension interactions to resolve anisotropy-induced discrimination errors. Experimental results demonstrate state-of-the-art performance across three key metrics: 40\% reduction in parameters, more than 5.3 times faster inference, and an 11\% improvement in mAP (IOU=0.3) compared to the dataset benchmark. This work advances radar perception by providing a resource-efficient solution specifically designed for embedded autonomous platforms while proposing a novel approach to address anisotropic feature learning in radar CNNs.
## Project Overview
### The proposed method is validated on the RADDet dataset, with the code implemented in PyTorch (version 2.0.1 + CUDA 118). The training script is named train_cart_w0_RADSuperivised.py, while all quantization and visualization evaluation codes are located in the "evaluates" directory.
